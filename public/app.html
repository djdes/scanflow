3 шага и ScanFlow готов работать

Каждый занимает пару минут. Шаг 2 можно пропустить — банк подключите потом из настроек.

  1. 1Накладная
  2. 2Банк
  3. 31С
  1. Шаг 1 Активный

    Отсканируйте первую накладную

    Загрузите фото или PDF любой накладной — за 3 секунды получите распознанные позиции, поставщика и сумму. Это твой первый тест системы.

    Загрузить накладную
  2. Шаг 2 Заблокирован Можно пропустить

    Подключите банк — черновики платёжек автоматом

    Подключите СберБизнес — из каждой одобренной накладной автоматически появится черновик платёжного поручения. Подписание токеном остаётся на твоей стороне, ScanFlow только готовит документ.

    Подключить СберБизнес
  3. Шаг 3 Заблокирован

    Подключите 1С — приходные накладные автоматом

    Скачайте внешнюю обработку .epf и поставьте её в Конфигуратор 1С:УНФ один раз. После этого 1С сама забирает одобренные накладные из ScanFlow и создаёт «Приходную накладную» с товарами, контрагентом и фото.

    Скачать обработку (.epf)

Выберите режим распознавания накладных

Используется только в режиме «Диспетчер». Возьмите токен в своём ProjectsFlow-аккаунте.
UUID проекта в вашем ProjectsFlow, куда будут ставиться OCR-задачи. Найдите его в URL проекта или через pf_list_projects.
Включено
Claude получает ваш справочник 1С вместе с фото накладной и сам выбирает подходящий товар для каждой позиции. Точнее, чем fuzzy-поиск по буквам, и не добавляет отдельных API-вызовов — всё в одном запросе OCR.
Включает кнопку «Заполнить по ИНН (DaData)» в карточке поставщика — подтягивает название, КПП и адрес по ИНН. Бесплатный тариф: dadata.ru.

Автоматизация после распознавания

Выключена
Сразу после успешного распознавания накладная помечается как одобренная (`approved_for_1c=1`) и подтянется в 1С на следующем pull'е. Дубликаты и накладные с ошибкой OCR пропускаются.
Выключена
Сразу после распознавания создаётся черновик платёжного поручения в СберБизнес. Поставщик должен быть `verified=1` в Поставщиках, иначе автоотправка тихо пропускается (только лог) — нужно вручную подтвердить реквизиты при первой отправке.

Как получить Chat ID и Bot Token
  1. 1
    В Telegram найдите @BotFather, напишите /newbot, дайте имя — получите токен вида 123456789:ABC….
  2. 2
    Вставьте токен в поле Bot Token выше.
  3. 3
    Найдите свежесозданного бота по username и нажмите Start (или напишите /start).
  4. 4
    Нажмите кнопку «Найти» возле поля Chat ID — он подставится автоматически, в Telegram придёт подтверждение.
  5. 5
    Нажмите «Сохранить», затем «Отправить тестовое сообщение» для проверки.

Какие события присылать

Срочные события всегда отдельным сообщением, остальные обновляют один thread на накладную

Если задан — урджентные события (повышенные цены, ошибки) продублируются на почту.
