# Обновление обработки 1С без Конфигуратора

`epf.js` обновляет обработку `КНД_ЗагрузкаНакладныхСканер` прямо в базе 1С, если менялся **только модуль объекта** (`Ext/ObjectModule.bsl`). Изменились формы или реквизиты — собирайте в Конфигураторе.

```bash
export MCP1C_TOKEN=…            # токен из формы MCP Toolkit в 1С (Настройки → MCP Toolkit); в git не класть
node 1c/tools/epf.js backup 1c/КНД_ЗагрузкаНакладныхСканер/было.epf      # что стоит в 1С сейчас
node 1c/tools/epf.js build  <база.epf> 1c/КНД_ЗагрузкаНакладныхСканер/ЗагрузкаНакладных_vN.epf
node 1c/tools/epf.js check  1c/КНД_ЗагрузкаНакладныхСканер/ЗагрузкаНакладных_vN.epf   # компиляция в 1С, без записи
node 1c/tools/epf.js deploy 1c/КНД_ЗагрузкаНакладныхСканер/ЗагрузкаНакладных_vN.epf   # запись в «Дополнительные отчёты и обработки»
```

- **build** берёт собранный `.epf` (лучше — тот, что скачал `backup`) и меняет в нём только текст модуля объекта на текущий исходник. Всё остальное остаётся байт в байт, и скрипт это проверяет. Формат контейнера описан в `v8container.js`, как в v8unpack.
- **check** подключает файл в сеансе MCP Toolkit (`ВнешниеОбработки.Подключить` + `Создать`): если в модуле синтаксическая ошибка, 1С её назовёт. В справочник ничего не пишется.
- **deploy** работает как форма элемента БСП: записывает хранилище со сжатием 9 и `ИмяФайла`, команды и расписание не трогает. Откат: `deploy` старого файла из `backup`.
- MCP Toolkit — обработка внутри 1С с сервером MCP (по умолчанию `http://192.168.33.213:6004`, переменная `MCP1C_URL`). Сервер должен быть запущен в форме MCP Toolkit.
- На `:6004` работает база SUB компании zakupki («Я Так Ем»), на `:6003` — MAG основного аккаунта. Проверено через MCP 09.10.2026: УНФ 1.6.27.295 / 1.6.18.168 соответственно. Перед проверкой или обновлением обработки всегда определить базу по документу, а не только по адресу сервера.
- Подключения MCP к обеим базам хранятся в настройках Claude Code, а не в репозитории. Заголовки авторизации не выводить в журнал и не копировать в репозиторий.
- В MAG включена анонимизация ответов MCP, которая может заменять фрагменты Base64 и повреждать выгрузку `.epf`. Проверять целостность полученного контейнера; повреждённую выгрузку не использовать для сборки или отката.
