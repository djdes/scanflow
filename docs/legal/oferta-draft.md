# Оферта на платные тарифы ScanFlow — черновик

Состояние: **черновик, не опубликован.** Пока идёт открытая бета, сервис бесплатен
и работает по [пользовательскому соглашению](../../public/legal/terms.html) (`/terms`).
Оферту публикуют вместе с запуском оплаты (`docs/billing-robokassa.md`, шаги 1–6),
отдельной страницей `/oferta` по образцу `/terms` (шаблон в `public/legal/`, маршрут
в `src/api/server.ts`, реквизиты из `LEGAL_OPERATOR_*`).

Ниже — текст, в котором отмечены решения владельца: **[РЕШЕНИЕ: …]**. Их нельзя
заполнить из кода — это деловые условия. Перед публикацией текст стоит показать юристу.

## Текст

### 1. Термины

**Исполнитель** — <наименование оператора из `LEGAL_OPERATOR_NAME`>. **Заказчик** — индивидуальный
предприниматель или организация, принявшие оферту. **Сервис** — ScanFlow: сайт scanflow.ru,
личный кабинет, API и обработка для 1С. **Страница** — одно изображение или одна страница PDF,
поступившие на распознавание; XML-документ из ЭДО — [РЕШЕНИЕ: считается одной страницей / не
считается].

### 2. Предмет

Исполнитель предоставляет Заказчику доступ к Сервису по выбранному тарифу на расчётный период,
а Заказчик оплачивает доступ. Состав функций тарифов — на странице тарифов и в `#/billing`.

### 3. Акцепт

Оферта принимается оплатой выбранного тарифа. С момента зачисления оплаты договор считается
заключённым на условиях оферты в редакции, действующей на дату оплаты.

### 4. Тарифы

| Тариф | Цена за период | Страниц в период |
| --- | --- | --- |
| Старт | 0 ₽ | 50 |
| Pro | 990 ₽ | 1 000 |
| Бизнес | 4 990 ₽ | 10 000 |

Цены — [РЕШЕНИЕ: с НДС по ставке … / НДС не облагается на основании …]. Неиспользованные
страницы на следующий период [РЕШЕНИЕ: не переносятся / переносятся].

### 5. Оплата

Оплата — через Robokassa банковской картой, СБП или по счёту. Доступ по тарифу открывается
после того, как Robokassa подтвердит оплату (ResultURL), а не после возврата на сайт. Чек —
[РЕШЕНИЕ: по 54-ФЗ на адрес электронной почты плательщика].

### 6. Период и продление

Расчётный период — [РЕШЕНИЕ: календарный месяц с даты оплаты]. [РЕШЕНИЕ: Продление —
автоматическое списанием с сохранённой карты с уведомлением за 3 дня / новым платежом по
ссылке из письма]. Без оплаты следующего периода аккаунт переходит на тариф «Старт»; данные
сохраняются.

### 7. Лимит страниц

Когда страницы периода закончились, [РЕШЕНИЕ: распознавание новых документов
приостанавливается до начала следующего периода или перехода на старший тариф / каждая
следующая страница оплачивается по … ₽]. Документы, загруженные до исчерпания лимита,
распознаются полностью.

### 8. Отказ и возврат

Заказчик может отказаться от договора в любой момент, написав на <почта из
`LEGAL_CONTACT_EMAIL`>. [РЕШЕНИЕ: Возвращается плата за неиспользованные полные периоды /
пропорционально неиспользованным дням / начатый период не возвращается]. Возврат — тем же
способом, которым прошла оплата, в течение 10 рабочих дней.

### 9. Закрывающие документы

[РЕШЕНИЕ: УПД / акт за каждый период — в разделе «Оплата» кабинета и/или через ЭДО].

### 10. Ответственность

Сервис распознаёт документы ИИ-моделью; результат проверяет Заказчик перед отправкой в 1С и
подписанием платежей (раздел 2 пользовательского соглашения). Ответственность Исполнителя
ограничена суммой, уплаченной за текущий период, кроме случаев, когда закон такое
ограничение не допускает. [РЕШЕНИЕ: обязательства по доступности — без SLA в бете; если SLA
появится, указать процент и компенсацию.]

### 11. Персональные данные

Обработка персональных данных — по [политике](../../public/legal/privacy.html) (`/privacy`),
данные из документов Заказчика — по поручению из раздела 5 пользовательского соглашения.

### 12. Изменение и срок действия

Исполнитель может изменить оферту и тарифы, предупредив Заказчиков по электронной почте не
позднее чем за [РЕШЕНИЕ: 14 / 30] дней. Оплаченный период действует на прежних условиях.
