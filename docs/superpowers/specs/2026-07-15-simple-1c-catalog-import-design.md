# Быстрый импорт каталога 1С — дизайн

## Задача

Новый пользователь должен оценить сопоставление номенклатуры без установки внешней обработки и без участия программиста 1С. Сейчас каталог принимается только через JSON API из обработки.

## Пользовательские сценарии

1. **Буфер обмена, 2–3 минуты.** Пользователь открывает список номенклатуры в 1С, выводит нужные колонки, копирует таблицу и вставляет её на сайте.
2. **Excel/CSV, 5–10 минут.** Пользователь выполняет стандартную команду 1С «Ещё → Вывести список…», сохраняет XLSX/CSV и загружает файл на сайт.
3. **Полуавтомат, 2–3 минуты на обновление.** Пользователь периодически повторяет выгрузку и загружает новый файл в режиме добавления/обновления.
4. **Автомат, 20–40 минут один раз.** После оценки пользователь подключает внешнюю обработку и регламентную синхронизацию.

Оценки ориентировочные: время зависит от прав пользователя и расположения команд в конкретной конфигурации 1С.

## Интерфейс

Во вкладке «Операционный центр → 1С» появляется карточка «Быстрый старт без программиста»:

- выбор или перетаскивание `.xlsx`, `.csv`, `.tsv`;
- вставка скопированной из Excel/1С таблицы;
- режим по умолчанию «добавить и обновить» без удаления каталога;
- отдельная явная опция полной замены с подтверждением;
- короткая последовательность действий и время;
- результат импорта: прочитано, загружено, пропущено, распознанные колонки.

## Распознавание таблицы

- Заголовок ищется в первых 25 непустых строках, поэтому допускаются заголовок отчёта и пустые строки 1С.
- Поддерживаются русские и английские варианты колонок: наименование, код/артикул, единица, GUID/UUID, полное наименование, группа.
- Обязательна только колонка с названием. Для таблиц без заголовка поддерживается одна колонка «Название» или две колонки «Код, Название».
- Если GUID отсутствует, создаётся стабильный локальный идентификатор из кода и названия. Это позволяет оценить сервис, но при переходе на прямой обмен отдельные ручные соответствия могут потребовать проверки.
- Формулы не вычисляются. Пустые и явно служебные строки пропускаются.

## Безопасность

- Только администратор, как и для существующей синхронизации каталога.
- Один файл до 5 МБ, не более 50 000 строк и 100 колонок.
- Только современные XLSX и текстовые CSV/TSV; старый бинарный XLS не принимается.
- Сначала файл полностью проверяется, и только затем выполняется запись или очистка каталога.
- Полная замена не является режимом по умолчанию.
- UI экранирует серверные значения; содержимое таблицы не исполняется.
