# Вход на телефоне по QR

В профиле открытого кабинета кнопка «Показать QR» создаёт код для входа в этот аккаунт. Камера телефона открывает `/m/`, установленное приложение считывает код с фотографии. После сканирования мобильный интерфейс использует тот же сеанс, что и при входе по паролю. Открытый на телефоне аккаунт сохраняется.

Сервер кодирует ссылку с одноразовым случайным токеном во фрагменте URL. Код действует две минуты, новый код заменяет предыдущий. В БД хранится SHA-256 токена. Обмен выполняется атомарно, блокировка аккаунта запрещает выдачу сеанса. Генерация и обмен работают на сервере ScanFlow.
