# Подбор позиции по использованию в 1С

Задача ProjectsFlow: `77e43a57-b541-4267-8099-27f561eb7a58`.

При неоднозначном названии сначала отбираются подходящие позиции каталога компании. Вид продукта, указанные характеристики, отклонения и подтверждённый человеком выбор важнее популярности. Среди оставшихся вариантов выбирается позиция с наибольшим числом разных спецификаций; при равенстве — с наибольшим числом проведённых приходных накладных. Если статистика не различает кандидатов, сохраняется обычный подбор.

Проверяется вся история, без ограничения по дате. Помеченные на удаление спецификации и приходные документы исключаются. Частота — число разных спецификаций/документов, а не строк или количество ингредиента. Группировка по ссылке номенклатуры, не по названию. Спецификации и приходы агрегируются отдельно, чтобы соединение не перемножало строки.

Источник — MCP toolkit соответствующей компании. Приватная серверная переменная `ONEC_USAGE_MCP_CONFIG` содержит JSON с явным соответствием id владельца → url/token. Общего источника по умолчанию нет. Секреты не хранятся в репозитории и не возвращаются клиенту. Максимум 40 кандидатов за вызов; параметры запроса — ссылки по проверенным GUID; кэш час и короткая пауза после ошибки. Недоступность 1С оставляет обычный подбор с честным пояснением.

Проверка применяется и к обычному подбору, и к выбору ИИ: при распознавании, повторном подборе и предложениях очереди. Сохранённое подтверждение и поставщицкое правило не пересматриваются. Смена позиции по статистике не записывается как подтверждённое правило; упаковка от другой позиции не переносится.

Объяснение с числами, сравниваемыми вариантами и временем проверки сохраняется в `invoice_items.mapping_reason` и показывается рядом с позицией. Ручной выбор и собственное название заменяют прежнее объяснение. Предложения очереди сохраняют объяснение при применении и откате.

Проверка MCP MAG: у «Бекон Варено-Копченый Буженаль Замороженный» 2 спецификации и 3 проведённых прихода. Это проверка канала, а не основание подключать MAG ко всем компаниям.
