# Режим распознавания `gpt` — фото читает GPT по своей подписке ChatGPT

**Дата:** 2026-10-06
**Статус:** реализовано в рабочей копии, не выкатывалось.

## Зачем

Сравнить GPT и Claude на реальных накладных и держать второй движок наготове. Подписка
ChatGPT подключается в самом ScanFlow входом по коду (как `codex login --device-auth`) —
без API-ключа OpenAI и без ProjectsFlow.

## Решения

- **Режим `analyzer_config.mode = 'gpt'`.** Включается в настройках (только admin) и только
  при действующем подключении ChatGPT. По умолчанию в проде остаётся `claude_api`: выкатка
  поведения не меняет.
- **Подключение** (`src/chatgpt/`, маршруты `/api/chatgpt/*`, только admin):
  - вход по коду: `auth.openai.com/api/accounts/deviceauth/usercode` → админ вводит код на
    `auth.openai.com/codex/device` → опрос `deviceauth/token` с интервалом от OpenAI → обмен
    кода на токены (`/oauth/token`, публичный client id Codex CLI);
  - токены — в `chatgpt_connection` (миграция 82, одна строка на платформу), только
    зашифрованные (AES-256-GCM, ключ из `JWT_SECRET`, отдельный от секретов Сбера);
  - access-токен обновляется за 5 минут до конца и при 401. Refresh-токен одноразовый:
    обновление одно на процесс (общий промис) и пишется с проверкой версии строки;
    отказ OpenAI переводит подключение в «нужен повторный вход»;
  - 429 ставит паузу подключения до сброса лимита (из ответа или заголовков);
  - кнопка «Проверить связь» — короткий запрос к модели.
- **Запросы** — бэкенд Codex `https://chatgpt.com/backend-api/codex/responses` (внутренний адрес,
  весь доступ — в `codexClient.ts`): `Authorization: Bearer`, `chatgpt-account-id`,
  `originator: codex_cli_rs`, `store: false`, поток событий.
- **Прокси.** OpenAI не обслуживает Россию: `OPENAI_PROXY_URL`, если пусто — `ANTHROPIC_PROXY_URL`.
  С машины разработчика `auth.openai.com` без прокси недоступен, `chatgpt.com` доступен.
- **Конвейер общий с Claude.** Те же системные инструкции, JSON-схема (для OpenAI — строгий
  режим), проверка с одним до-чтением, отдельное чтение чисел и сверка строк, определение
  поворота. Выбор движка — по имени модели (`isGptModel`), поэтому прогон эталонов и
  перераспознавание очереди меряют модель из настроек (`visionModelFor`).
- **PDF в режиме `gpt` читает Claude.**
- **Модель** — `analyzer_config.gpt_model` (миграция 81), по умолчанию `gpt-6.1-sol`; в
  настройках также `gpt-6-luna` и `gpt-6-astra`.

## Риски

- **Условия OpenAI.** Подписка ChatGPT рассчитана на личное использование; бэкенд Codex —
  внутренний адрес без документации и может измениться. Для постоянной работы сервиса
  надёжнее ключ OpenAI API.
- **Лимиты подписки.** Исчерпан лимит — распознавание в режиме `gpt` падает с понятной ошибкой
  до времени сброса; откат — переключить режим на `claude_api`.
- **Прокси.** Без рабочего прокси на сервере не пройдут ни вход, ни запросы.

## Как включить и откатить

1. Выкатить: миграции 81 и 82 применятся при старте. При необходимости задать `OPENAI_PROXY_URL`.
2. Настройки → режим «GPT (подписка ChatGPT)» → «Войти по коду», ввести код на сайте OpenAI,
   «Проверить связь», выбрать модель, сохранить.
3. Сравнить на эталонах: прогон в режиме `claude_api`, затем в `gpt`.
4. Откат — вернуть «Только Claude API», без выкатки. «Отключить» удаляет токены из БД.
