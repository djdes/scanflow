# Синонимы товаров

У выбранной позиции накладной есть кнопка «Синонимы». Также список доступен в «Номенклатура → Справочник 1С» у каждого товара. Можно добавить несколько названий из накладных, каждое с новой строки. Синонимы участвуют в поиске, подборе при распознавании и подсказках.

Синоним — подтверждённая человеком строка `nomenclature_mapping_cards`, а не копия названия товара в 1С. Каталог и бухгалтерские поля накладной не переименовываются. Уже существующие подтверждённые варианты показываются в этом же списке. Не подтверждённые предположения ИИ в синонимы не включаются.

Прямое подтверждённое правило сильнее нового предложения ИИ и сравнения популярности в 1С; для этого не требуется подключать источник статистики 1С. Явно подтверждённый переход между разной жирностью допустим (например, историческое учётное название майонеза). Для остальных товаров обычные проверки атрибутов сохраняются. Правила конкретного поставщика сохраняют прежний приоритет. Сохранение синонима снимает отклонение этой позиции для того же названия.

Хранятся конкретные названия и их нормализованные ключи товара. Из двух подтверждённых майонезов не создаётся общее правило для всех марок или любой жирности. Подтверждённый синоним, уже принадлежащий другому товару, нельзя незаметно переназначить через добавление: API возвращает конфликт. Изменение существующего соответствия доступно в разделе «Номенклатура».

API: `GET/POST /api/nomenclature/:guid/aliases`, `DELETE /api/nomenclature/:guid/aliases/:id`. Добавление принимает `{ "aliases": ["Название из накладной"] }`, до 50 названий по 500 символов за запрос. Пачка сохраняется одной транзакцией, с фиксацией автора и журналированием. Удаление также забывает правило поставщика для этого точного названия и той же позиции; остальные синонимы не затрагиваются. Все операции ограничены владельцем компании, включая GUID, совпадающий в каталогах разных компаний.
